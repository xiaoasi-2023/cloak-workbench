# 栖航工作台 · 品牌草案

暂定中文名“栖航工作台”，英文名 Qihang Workbench。账号在独立环境中安放，任务按明确航向推进。图标以两个错位窗口表达独立环境，右上航向标表达启动与自动化；使用现有界面的薄荷绿与深绿。它是本项目的原创几何草案，不使用 CloakBrowser、Google 或 Dola 的标识。

`qihang.svg` 是可编辑的矢量源；`qihang-256.png` 用于预览；`qihang.ico` 包含 16、20、24、32、40、48、64、128、256 像素尺寸。大尺寸绘制通过 `tools/render_branding.py` 输出并缩小，小尺寸保留窗口与航向的轮廓。正式发布前需在 Windows 桌面和任务栏按实际尺寸验收。

`release/branding.json` 集中记录名称、作者、联系方式、版本及图标位置，已用于内部安装包、程序文件属性及安装版标题。作者 Qihang Studio 为占位名称；联系方式留空时显示“暂未设置”，不提供虚构邮箱。版本 0.1.0-beta.1 为首次安装包验收版，完成干净系统验收后再发布 1.0.0。

正式接入时，从同一配置生成窗口、关于页、EXE 文件属性、安装向导和卸载项中的信息，避免各处分别改名。Windows 的“已验证发布者”来自代码签名证书，不能通过修改作者文字获得。
