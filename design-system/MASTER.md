# Cloak Workbench 设计规范

## 产品与视觉方向

Windows 原生浏览器环境工作台，以紧凑、清晰的生产力界面承载真实网页。主操作区使用浅色背景与白色表面，深色窄侧栏提供稳定定位；浏览器视口保留尽可能多的操作空间。

## 字体与尺寸

- 全局使用 `Microsoft YaHei UI`，确保中文和英文在 Windows 中清晰、统一。
- 技术信息使用 `Cascadia Code` 或 `Consolas`。
- 页面标题 23 px，分区标题 15 px，主要正文 13 px，辅助信息 11–12 px。
- 初始窗口 1440 × 900，最小 1050 × 680；原生窗口保留系统标题栏。
- 左侧导航 76 px，环境列表 278 px；主区间隔 16 px，外边距 20 px。
- 表面圆角 10–12 px，按钮 7 px，输入框 6 px。

## 控件与交互

- 自定义 WPF Button、TextBox、PasswordBox 模板，去除系统浮雕样式。
- 图标由统一的 24 × 24 Path 几何绘制，圆角描边 1.7 px；不用 emoji 充当图标。
- 图标按钮提供 ToolTip 与 UI Automation 名称。
- 键盘焦点可见；悬停只改变透明度，不改变控件尺寸。
- 保存操作位于编辑器固定底部；编辑内容可以滚动。
- 每 2 秒状态轮询保留没有变化的控件实例，避免抢走键盘焦点。
- 原生浏览器输入、中文候选框、文件选择框继续使用内核和 Windows 原生机制。

## 配置与结果表达

- 编辑器分为基本信息、网络代理、浏览器指纹。
- 代理密码使用 PasswordBox；区分留空保留和主动清除。说明密码保存在本机环境配置。
- 代理检测显示实际连通性、出口 IP、耗时与网络模式；请求期间禁用重复触发。
- 指纹字段读取真实内核能力，不支持项禁用。窗口初始尺寸和网页暴露的屏幕尺寸分别标注。
- 验证界面并列展示配置、实际值和状态。自动值、未暴露值、未验证项分别表达；不把配置成功写成生效验证。
- 下载列表只展示环境下载目录中的实际文件，时间使用本地可读格式。
- 弹窗管理只列出当前浏览器进程拥有的独立窗口，显式切换或请求关闭；不处理 IME 候选框。

## 验证

使用实际 WPF 模板解析与布局渲染检查视觉结构，再检查有账号和真实浏览器内容的工作台。确认 1050 px 最小宽度下工具栏、账号操作与编辑器没有遮挡；输入行为以真实 Windows 键盘验证为准。
