# 安装包

用户只需运行 `Qihang-Setup-0.1.0-beta.2-win-x64.exe`，安装后点击“栖航工作台”。安装包包含运行库和 CloakBrowser 146 内核，不要求另外安装 Python、.NET 或 Chrome。

`0.1.0-beta.2` 新增页面内“备份与恢复”，支持携带企业授权与代理的密码加密配置包，以及可选账号、环境设置和绑定迁移。导入预览、冲突处理、导入前自动备份与异常回滚均已接入。详细操作与授权有效期限制见项目 README 的“跨电脑配置备份与恢复”。

`0.1.0-beta.2` 验收：后端 233 项（229 通过、4 可选跳过），其中配置迁移专项 14 项；真实 WPF 页面 16 项；实际安装后运行 13 项；安装 / 卸载生命周期 7 项。安装验收覆盖从不存在的用户资料目录首次启动，以及随包加密导出、解密预览、恢复和导入前备份。Google 刷新使用离线模拟响应，不将此测试等同于真实令牌仍有效；未操作生产企业或账号。

## 当前交付内容

当前仅构建一个**离线完整安装包**。文件名中的 `Setup` 表示安装程序，其内容对应早期方案中的 `Offline`，已内置浏览器内核。没有额外的首次内核下载步骤；在线精简包和独立内核组件包尚未实现。

| 组件 | 安装后的位置 | 作用 |
| --- | --- | --- |
| 启动入口 | `Qihang.exe` | 启动后台、等待就绪、打开桌面界面并管理退出清理 |
| Python 3.13 后台与依赖 | `Qihang.exe`、`_internal/` | 冻结打包的后台代码、Python 解释器及依赖，负责账号、代理、企业目录、自动化与任务处理 |
| WPF 桌面程序 | `app/CloakWorkbench.exe` | 工作台窗口、列表、配置和浏览器窗口承载 |
| .NET 8.0.32 运行库 | `app/` | 运行 WPF 界面；采用自包含发布，仅供随包程序使用，不安装开发 SDK |
| CloakBrowser 146.0.7680.177.5 | `engine/chromium-146.0.7680.177.5/` | 完整 Chromium 浏览器内核及图形、语言等资源，按环境加载独立浏览器资料 |
| 品牌与许可 | `branding.json`、`licenses/` | 软件名称、版本配置、使用说明及第三方许可 |

用户双击快捷方式后，`Qihang.exe` 先以 `--worker` 模式启动另一个自身进程，加载随包 Python 后台。后台在 `127.0.0.1` 的随机端口启动，入口验证其就绪状态后再启动 WPF 窗口，界面通过带会话令牌的本地接口调用后台。用户打开浏览器环境时，后台启动随包 CloakBrowser，桌面程序将浏览器窗口嵌入工作区。正常关闭工作台时，入口协调关闭后台和相关浏览器进程。

这里的“离线”指安装和准备运行组件无需联网；Google 授权、代理检测、Dola 登录等在线功能仍需网络。打包并未把 Python 改写为 C#，而是将原有程序及其运行环境一起交付。

## 安装与数据

程序安装在 `%LOCALAPPDATA%/Programs/QihangWorkbench`，账号、代理和浏览器资料保存在 `%LOCALAPPDATA%/QihangWorkbench`。安装包不含开发机数据，卸载默认保留用户资料。本包为本人 / 组织内部使用版。

安装向导使用简洁的欢迎页与安装完成页；完整使用与许可说明随程序保存在 `licenses/internal-use.txt`，不在安装流程中展示品牌草稿或开发说明。

## 开发者构建

开发者构建：

```powershell
.venv\Scripts\python.exe -m pip install pyinstaller==6.16.0
.venv\Scripts\python.exe tools\build_installer.py
```

构建机需要项目内 .NET SDK、完整内核和 Inno Setup 编译器。默认编译器路径 `.tools/inno-portable/tools/ISCC.exe`，也可通过 `--compiler` 指定；`--browser` 指定完整内核目录。构建工具无需安装在用户电脑。输出位于 `dist/`，同时生成 SHA-256 校验文件。

构建只复制冻结程序、自包含桌面程序、内核和许可文件，不复制 `data/`、`.local/`、`.venv/` 或 `.tools/`。程序仍沿用原有源码启动方式；安装版使用独立用户目录及随机本地端口，可与开发版并行，互不读写账号资料。

安装包名称、作者与版本从 `branding.json` 读取；内核目录、用户数据目录和升级身份保持稳定。软件名“栖航工作台”与作者 Qihang Studio 暂定；当前没有代码签名证书。

冻结程序验收命令（使用隔离空白资料，仅访问本机测试页面）：

```powershell
.venv\Scripts\python.exe tests\installer_smoke.py --app .local\package-build\payload\Qihang.exe --out .local\package-smoke
```

这是包含内核的简单离线安装版，不实现在线组件下载或自动更新。前期完整设计中的组件平台和迁移功能仍属于后续规划。
