# 工作台关系与交互整理

日期：2026-10-15。对应审查：[功能关系与交互审查](product-flow-audit-2026-10-15.md)。

## 已完成

- 浏览器第二列仅展示运行环境，卡片改为紧凑行，可整体折叠。顶部标签、数量、重启清单统一包含独立窗口；独立窗口有切换与嵌回入口。
- 环境管理负责保存环境和批量操作。详情分为概览、账号、代理、指纹、登录备份；行内保留打开和检测代理。
- 新建和编辑环境共用页内设置，集中名称、分组、备注、账号绑定、代理和指纹。运行中仅保存资料；关闭后可调整账号、代理、指纹和启动配置。
- 账号列表提供“为此账号创建环境”以及打开已有绑定环境。新环境预选对应 Google 账号，保存不会自动打开或发起登录。账号明文密码显示保持现有方式。
- 环境设置在普通切页和代理管理往返时保留未提交资料；取消或保存后释放该草稿。草稿不跨软件退出保存。
- Dola 检测区分当前运行实例与历史记录。历史不计入本次已登录；账号绑定和网站身份核验独立表达，未绑定的手动登录环境有效。
- 登录检测时间与网络检测时间独立。代理列表优先展示国家、连接、质量、绑定和时间，技术列可展开；检测选择规则统一为优先勾选，否则高亮行。
- 代理新增、编辑和检测详情使用页内视图；保留原表单工厂供既有测试复用。环境检测优先查询当前保存环境的实际住宅会话，配置草稿检测明确标为线路快照。
- 出口与语言或时区不一致时在详情提示，调整仍须用户保存；不会在运行中改变固定指纹。匹配地区并不保证 Dola 支持该出口。
- 登录备份明确说明使用备份创建恢复环境，保留原环境；恢复数据与确认网站登录分别处理。
- 工作台底部状态跨管理页面显示进行中的环境、代理及 Google 登录活动。

## 生命周期与异步修复

- 独立窗口不再从运行数量中消失；再次嵌入复用原窗口、进程与网页。
- 当前独立窗口自行关闭时，显示剩余运行环境；重复恢复已有实例不会重新导航，避免清空网页草稿。
- 重启清单保留内嵌或独立窗口模式，去重并排除已关闭环境。
- 迟到的代理检测结果不会覆盖后来选择的线路或修改后的手动认证。退出代理检测页面期间返回的任务编号会被取消，避免遗留定时器与检测任务。
- 页内保存防止重复提交和提交期间取消。回到其他页面后保存完成不会抢回前台。
- 本地 API 读取遇到连接中断会有限重试；写入请求不自动重放。

## 本轮边界

没有新增 Google 邮箱密码批量导入、集中任务调度或自动识别绑定邮箱的能力。Google 账号库之外的旧环境凭据读取暂时保留，后续迁移需要单独处理已有绑定关系。验证码、两步验证与网站风控继续沿用原来的暂停机制；本轮 Google 登录回归使用隔离流程，不冒充真实第三方登录验证。
